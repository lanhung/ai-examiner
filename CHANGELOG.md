# Changelog

All notable released versions of AI Examiner are recorded here.

## v0.3.0 — Multimodal evidence and dataset engineering

- Added page-level PDF evidence, previews, coordinates, and highlighted crops.
- Added PPTX and DOCX extraction.
- Added visual evidence analysis and multi-document joint review.
- Added dataset lifecycle, diffing, prompt registry, background jobs, cost reporting, and provider health.
- Added Redis/Celery production Compose topology and Vultr deployment/backup documentation.

See `RELEASE_NOTES_v0.3.md` and `docs/releases/v0.3.0/`.

## v0.2.0 — AI-curated Golden Dataset and model benchmark

- Added multi-model annotation, critique, consensus synthesis, and synthetic answer generation.
- Added Planner/Analyzer benchmarks, model ranking, cost/latency tracking, and expert-agreement inputs.

See `RELEASE_NOTES_v0.2.md` and `docs/releases/v0.2.0/`.

## v0.1.0 — Text AI examiner MVP

- Added document upload, text examination workflow, follow-up policy, evidence-based scoring, and reports.
- Added mock and OpenAI provider paths, Docker deployment, tests, and developer-agent role definitions.

See `docs/releases/v0.1.0/`.
