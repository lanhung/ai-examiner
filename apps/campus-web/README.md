# 答辩学堂：独立网页版

独立目录、独立进程和端口的 FastAPI 浏览器网关，不覆盖原 AI Examiner 网站或微信客户端。正式考试、答卷、成绩仍由原后端统一存储和授权；本项目只增加网站账号的凭据存储。

## 账号注册与登录

- 注册：`/#register`，用户名 3–32 位字母、数字或下划线（不区分大小写），显示名称 1–40 字，密码 12–128 位且两次一致。
- 登录：`/#login`，不需要微信确认或配对码。注册成功后使用新账号登录。
- 新账号默认学生，首次登录创建独立个人空间；可查看小程序教师公开发布的考试。提交答卷仍需确认将姓名、答卷和成绩提供给发布教师。
- 不按姓名合并微信身份、历史成绩或教师权限。教师权限需要管理员核验后按原后端授权流程开通，学生不能自行选择成为教师。
- 密码使用随机盐和 scrypt 存储；不保存明文密码。浏览器只持有随机 HttpOnly / Secure / SameSite=Strict Cookie，不持有后端令牌。
- 网关闲置上限 2 小时，绝对上限 24 小时，同时受原后端更严格的会话期限约束。退出会撤销后端会话，进程重启须重新登录，账号和成绩不会丢失。
- 登录和注册有持久化限流。当前单机代理的客户端地址可能合并为网关地址，大班集中注册需关注 10 分钟内 12 次注册、50 次登录的地址限额；不能信任客户端自行传入的 X-Forwarded-For。
- 尚未实现自助找回密码、邮箱验证、MFA 和微信账号绑定；不要承诺通过输入姓名即可恢复旧账号。

## 数据与权限边界

网站凭据 SQLite：`/var/lib/examiner-campus-web/accounts.sqlite3`，目录 0700、文件 0600。

原业务库：首次登录按新账号 UUID 建立 `campus:password:v1` 身份、独立组织、个人答辩权限和审计事件。原有 PostgreSQL RLS、教师授权和考试权限校验继续生效。撤销的成员关系不会被再次登录自动恢复。

只有受信同机服务读取私有运行配置的数据库、身份、会话及审计配置。不会读取千问 Key、微信 AppSecret，不改原后端源码。账号模块依赖同机原工程的身份服务与表结构；原后端升级时需重跑身份集成测试。

`companion/` 和 `wechat-companion-port80/` 是旧配对方案留档，本版不再使用；无需重新发布小程序才能使用网页账密登录。

## 已接入业务

| 入口 | 能力 |
| --- | --- |
| 学生考试大厅 | 公开考试、材料、报名、异步作答、答卷与成绩 |
| 教师工作台 | 已授权教师的材料、出题、发布、试答、成绩及复核 |
| 个人答辩 | 独立个人空间、上传、异步蓝图、文本答辩与报告 |

模型固定 `qwen:qwen-plus`。本网页版尚未移植录音转写、语音播放和实时语音。未登录首页是公开合成案例，正式大厅只在登录后展示。

### 个人答辩报告

在已完成的对话中点击「查看报告」，会进入独立地址 `/#report/<会话ID>/student` 或 `/#report/<会话ID>/teacher`。可直接刷新、用浏览器前进后退或点「返回答辩」。未登录时须先登录；该地址不会授予他人查看权限。

顶部列出综合评分及题数，评分分析和作答证据可与改进建议对照。每页显示五条证据；「打印报告」使用浏览器打印或另存为 PDF，包含所有证据和材料出处，不只打印当前页。报告读取超时可单独重试，不重新交卷。

## 本地开发

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m uvicorn campus:app --host 127.0.0.1 --port 8031 --no-access-log
```

在 Git 仓库中，本项目位于 `apps/campus-web/`。以上命令在该目录运行；工作台和微信小程序保持独立。本地默认只用于页面预览，注册和登录返回“账号服务尚未配置”。不把生产凭据复制到本地。

身份集成测试使用临时 SQLite 以及仓库根目录的 `src/ai_examiner`；独立目录开发也兼容相邻的 `../ai-examiner/src`。请使用已安装主仓库开发依赖的 Python 运行测试，不连接生产数据库。

## Casdao 部署

独立新站：[答辩学堂](https://classic-merry-6705-80.east3.casdao.com:2005/)。代码 `/opt/examiner-campus-web`，Supervisor 服务 `examiner-campus-web`，监听 80，原 8000、6008 服务保持不变。

`CAMPUS_ORIGIN` 为实际 HTTPS origin（含平台端口）；同机 `CAMPUS_UPSTREAM=http://127.0.0.1:8001`。启动脚本绑定端口、读取身份配置后立即降权；文件存储与配置临时目录单独置于 `/var/lib/examiner-campus-web`。

仅重启新站：

```sh
supervisorctl restart examiner-campus-web
curl -fsS http://127.0.0.1/api/me
curl -fsS http://127.0.0.1:8001/ready
```

`ops/update_password_auth.py` 用于将 20261116 配对版升级为账密版：逐文件核对基线 SHA-256，备份旧文件，部署后检查新旧服务；失败只回滚新站代码。重复执行会安全拒绝，不能用于任意后续版本覆盖。SSH 密码交互输入，不写文件。

`ops/casdao.py --install --port 80` 仅适用于目录、端口都空闲的全新安装，不覆盖已有服务。当前按单进程部署，网页登录会话在内存中，不能直接扩成多个 worker。

## 备份与恢复

必须同时备份**网站账号 SQLite**和**原业务数据库及材料**。网站账号 UUID 用于映射业务身份，不能丢失凭据库后按用户名重建。备份包含敏感密码哈希，需加密、限制权限，不能上传 GitHub。

在线 SQLite 快照可以通过 Python `sqlite3.Connection.backup()` 完成。恢复前停新站，核对对应业务库备份，恢复所有者 nobody、目录 0700、文件 0600，再启动。代码回滚不删除凭据库或业务记录。

```sh
node --check web/app.js
```
