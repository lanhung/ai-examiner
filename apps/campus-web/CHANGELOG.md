# 更新记录

## 2026-11-24：独立答辩报告页

- 「查看报告」改为学生 / 教师各自的可刷新页面，支持直接打开链接、返回原对话及浏览器前进后退。继续使用原有授权接口，未完成或无权访问的报告不展示评分。
- 按总评、评分分析、证据、反馈和改进计划排版。手机端可跳至章节；打印时展开全部证据和材料出处，结束后恢复原页。只改变呈现，不改变分数、数据或产品版本号。
- 已热更新独立校园站的三个静态文件，公网 SHA-256 一致。17 项本地浏览器回归通过；五档宽度（320 至 1440 像素）无横向溢出，示例 PDF 包含全部六条证据。线上公开页面以合成答卷验证了跳转、排版和打印；一次进入站点时脚本加载超时，单独重测通过。

## 2026-11-24：个人答辩回执与报告读取

- 最后一答已落库时，以服务端会话状态为准。恢复对话只保存请求编号和提交前轮数，不保存答辩正文，不自动重发。回执暂缺时先核对对话；仍在处理时允许手动查询，不能重复交卷。
- 点击“查看报告”立即打开可关闭的窗口。读取超过 15 秒可单独重试；切换会话或身份会丢弃旧请求。答题证据每页 5 条，不递归展开重复的模板数据。
- 报告只依赖已保存的回答和评分。网页网关仍校验角色及组织，但无需额外请求模型健康状态。
- 回归入口：`node --test tests/task_feedback.cjs`、`pytest test_gateway.py test_identity_bridge.py`；共享 API 的异步答辩与报告用例见 `tests/test_end_to_end.py`。
- 发布范围：仅热替换 Casdao 80 端口独立站的 HTML、JS、CSS，公网 SHA-256 与本地通过测试的文件一致。网关及共享 API 的 Python 优化已在本地测试，未重启线上服务。没有迁移数据、调整成绩或重新调用模型。
- 线上排查请区分打开站点超时与点击报告后超时：桌面 Edge 隔离浏览器曾在首个导航阶段超时，当时尚未请求报告。可设置 `CAMPUS_TEST_STATIC_ORIGIN` 验证实际发布的前端；测试只允许公开静态 GET，业务请求在浏览器内以合成数据应答。

## 2026-11-19：模型任务原地更新

- 独立网页版在生成蓝图、学生作答、教师试答和个人答辩时，只更新当前任务的状态与结果。后台查询不清空正文、不重建导航；长对话等待期间保留滚动位置与输入选区。
- 蓝图进度查询只取任务回执，不反复读取项目、材料列表。刷新后按已授权回执还原题目，不重新调用模型，浏览器会话存储只记标识符。
- 查询暂时失败时保留页面并重试读取，不自动重发答案；学校答卷在提交结果不明时，手动重试沿用同一请求编号。切页会忽略旧查询，权限失效仍会清除受保护内容。
- 七项慢响应浏览器回归：`node --test tests/task_feedback.cjs`（需要 Playwright 和 Edge/Chromium）。`ops/casdao_acceptance.py --scope feedback --max-calls 3` 可用真实千问在隔离库复验生成、刷新、交卷与教师成绩。此次上线只替换 HTML、CSS 和 JS，不涉及版本号、后端、账号或数据库变更。
- 本次上线验收：公网入口和两个静态资源与发布文件的 SHA-256 一致。两个隔离浏览器账号使用真实 `qwen-plus`（3 次模型请求成功）：蓝图生成和学生交卷各仅提交 1 次，两个等待阶段均检测到 0 次整页加载提示；刷新后 6 道题逐条一致，师生两端测试成绩均为 42 分。
