# 答辩学堂独立网页版：教师与学生验收

日期：2026-11-18。对象是 Casdao 的独立账密网站，不是原工作台或微信小程序。

## 正式站点检查了什么

- 在网站凭据库**按用户名精确匹配**一个已启用、已首次登录的账号。由运维通过已有授权服务开通教师权限，分配独立教师空间（成员角色 `examiner`），保留原学生空间。带审计记录；未授予组织管理权限、未与微信合并、未修改密码。
- 写入后，以普通应用数据库角色另建连接，用实际学校身份查询再次回读：教师为真、学生空间正常、教师空间与学生空间不同，未产生第二次写入。
- 新的 Edge 浏览器会话实访[正式入口](https://classic-merry-6705-80.east3.casdao.com:2005/)：首页 HTTP 200，可展开有 3 道题的公开示例，可点击进入登录和注册表单。未代替真实用户登录或查看真实成绩。

## 浏览器验收

通过 SSH 在同一服务器上加载**已部署的网站和考试服务代码**；单独进程降权运行，使用一次性 SQLite、独立凭据库、本地对象目录、内存任务队列。浏览器经仅回环可访问的临时监听访问网页，不将合成考试写入正式大厅。教师和学生使用不共享 Cookie 的两个 Edge 浏览器上下文，通过真实账号密码登录。没有改动或重启正式网站、API、队列或反向代理。

| 操作 | 观察到的结果 |
| --- | --- |
| 匿名浏览、注册、登录、退出 | 学生可注册并登录，没有教师导航；退出后再次打开“我的答卷”只显示登录提示。 |
| 切换角色 | 教师可从教师工作台返回学生考试大厅，再回到工作台；不用换账号。 |
| 准备试卷 | 教师建立新项目、上传合成水位研究 TXT；解析完成后能选择文件。真实千问生成中文材料的答辩蓝图，可发布 1 题考试。 |
| 学生领取材料 | 另一学生账号刷新后能看到新考试，材料预览包含原文的测量值；同一登录会话获取的原件与上传文件逐字节一致。另用合成附件独立复验真实浏览器点击下载，SHA-256 与原件一致。 |
| 教师试答 | 完成试答并获得模型评分 42/100，教师端此时仍显示正式答卷 **0 份**。 |
| 学生交卷 | 学生填写合成姓名和学号、确认提交、回答 1 题；学生看到 42/100，教师成绩表出现且仅出现该学员的 **1 份**正式答卷，对应分数相同。 |
| 复核与关闭 | 教师修改为 83.5/100 并填写复核理由；学生从“我的答卷”重新进入，看到了相同的新分数和理由。关闭报名后，既有学生仍能看成绩。 |
| 教师个人答辩 | 从教师个人答辩进入，考官首次提问、提交第一轮回答、再次展示已记录的回答均通过。完整多轮报告另有离线回归，本轮未用真实模型把个人答辩做到最终报告。 |

## 真实模型与耗时

两轮浏览器验收合计 **8 次真实 `qwen-plus` 请求，8 次成功**，只发送合成材料与回答；不是 Mock。实际计数为输入 15,743、输出 11,207 tokens，包含蓝图、试答评分、学生评分及个人答辩等。第三轮仅复验附件点击下载及退出，使用人工编写的附件样本，不读取模型密钥，模型调用数为 0。

- 两次蓝图模型请求分别为 69.2 秒、73.9 秒。
- 一份单题试答评分的两次模型请求耗时合计 35.0 秒；另一份学生答卷合计 34.2 秒。以上是供应商调用时间，不含排队、浏览器轮询等开销。样本少，不能作为 SLA、并发性能或评分准确率指标。

## 发现与复验

1. **刷新后蓝图题目预览消失，发布能力仍在。** 在“准备考试”生成蓝图后，可看到题目；刷新页面后仍有“发布考试”按钮，但题目列表为空。当前会话存储只保留蓝图 ID，页面没有恢复题目内容。建议按当前教师身份和空间重新读取已生成蓝图，并显示恢复进度，不要重新请求模型。验收条件：刷新前后题数、题文和蓝图 ID 相同，模型调用不增加。
2. **长等待可感知。** 单份简短 TXT 的两个真实样本也需要约 70 秒才返回蓝图。适合先分别度量排队、模型和轮询耗时，再决定是否减少生成题量或调整界面进度提示。
3. **以下两项不是产品缺陷。** 第一次自动下载取消，独立对照显示 Edge 下载管理器不发送额外测试请求头；临时访问检查改为兼容下载的 HttpOnly Cookie 后点击下载通过。退出时第一次断言同时匹配了导航登录按钮和内容区登录按钮；改为核对内容区后通过。两项均未改动正式应用。

## 其他回归与边界

- 12 项新网站账号、网关和身份测试通过，包含精确授权、幂等、独立教师空间以及其他学生不受影响。
- 37 项共享服务回归通过，涵盖考试、上传、异步蓝图、任务恢复、模型输出异常及完整文本报告。临时库须正常加载随项目发布的迁移、提示词和模板。这些回归使用离线测试配置，不计入上面的真实模型调用。
- 本次不等同于在正式库用真实学生名单开考；未进行生产 PostgreSQL RLS 全量复测、Redis/Celery 排队压测、微信端或音频测试。临时服务已退出。

## 再次运行

本机需安装 Python + Paramiko、Node.js、Playwright 及对应浏览器，并预先核验并保存服务器 SSH 主机指纹。脚本交互读取 SSH 密码，不把密码、模型密钥、会话或论文写入报告。

```powershell
python ops/casdao_teacher.py my_username                # 正式账号只读核对
python ops/casdao_acceptance.py --max-calls 8            # 隔离浏览器验收，会产生少量千问费用
python ops/casdao_acceptance.py --scope download         # 只复验附件与退出，不读模型密钥
```

Playwright 不在默认搜索路径时，传入 `--node-modules <node_modules目录>`。默认用无头 Edge；不使用个人浏览器配置。
