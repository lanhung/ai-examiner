# AI Examiner 微信小程序预览版

客户端版本：`0.1.0-preview`。后端保持 `0.9.0`，开发分支 `feature/wechat-miniapp`。

这是独立的原生 WXML/WXSS/JavaScript 客户端，不是网页套壳。复用现有 FastAPI、组织权限、文档解析、答辩和报告服务。

## 已实现

- 微信登录凭证交换；可选择管理员审批或自动独立个人空间，不自动加入已有组织。
- 空间及项目选择、创建项目、从微信聊天文件中选择论文。
- PDF/PPTX/DOCX/TXT/Markdown 上传，客户端上限 20MB；服务端限制仍有效。
- 已配置真实模型选择，列表排除 mock；可选模型仍受后端治理和额度约束。
- 异步答辩蓝图、任务状态刷新、题目预览。
- 自适应文字答辩、追问、最终报告。
- 登录失效处理、任务/最近会话 ID 恢复、结果不明时禁止重复发送回答。

## 导入

1. 在微信开发者工具导入本目录（包含 `project.config.json`）。
2. 把 `touristappid` 改为你自己的小程序 AppID。游客模式只能检查界面，不能完成真实微信登录。
3. 在 `miniprogram/config.js` 填写服务端 HTTPS origin，例如 `https://exam.example.com`，不要包含路径或末尾 `/`。
4. 先按照仓库 `docs/wechat/SETUP.md` 启用后端。仅运行旧版后端没有微信登录接口。
5. 后端 `WECHAT_REGISTRATION_MODE=personal` 时，新账号首次登录自动创建独立个人空间；默认 `approval` 模式仍显示申请编号，等待管理员授权。

不要在客户端填入 AppSecret、OpenAI Key、千问 Key。它们只属于服务器配置。

## 当前边界

- 这是开发预览版，已完成真实登录和开发者工具内的 qwen-plus 文字答辩验收；尚未提交微信审核，Android/iOS 真机仍待测试，不是完整网页版功能搬迁。
- 2026-09-23 实测发现开放题预设答案偏差、报告缺少逐题证据、消息滚动和终止任务锁定等问题，尚未修复。完整记录见 [实测报告](../../docs/wechat/ACCEPTANCE_2026-09-23.md)，不能将流程可用等同于评分质量达标。
- 尚未适配原生实时语音、页面证据图片查看、控制器管理、七场景模板编辑和历史会话列表。
- 每个账号/组织仅保存最近一条工作进度；切换项目会替换这条本地指针，但不会删除服务器数据。
- 已登录期间进度可恢复。主动退出或身份过期会清除本地进度，可从网页查看服务器记录。
- 答案接口目前为同步调用，超过 60 秒可能超时。客户端暂停重复提交，刷新确认；持续无法确认需到网页检查，不能把超时当作取消。
- “模型已配置”不是“已验证可调用”，真实额度、网络及回答效果仍需实测。
- 小程序隐私说明目前为预览文本；正式发布前必须由运营方补齐政策、联系方式和微信隐私接口适配。

## 自动化检查

在仓库根目录运行：

```bash
python -m pytest tests/test_wechat.py tests/test_oidc_authentication_v09.py tests/test_authorization_v09.py -q
node --test tests/wechat_client.cjs
```

Python 协议测试模拟微信兑换和模型响应，验证软件流程而非真实 AI 效果。Node 测试模拟 `wx`；不能替代微信编译器、iOS/Android 真机验收。
