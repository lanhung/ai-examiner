title: 哈希表
---
哈希表是一种根据键直接访问数据的结构。它通过哈希函数把键映射到数组下标，在理想情况下，查找、插入和删除的平均时间复杂度都是 O(1)。

不同的键可能被映射到同一个位置，这称为哈希冲突。冲突无法完全避免，常见的处理方法有两类。链地址法在每个数组位置保存一个链表（或平衡树），冲突的元素放在同一条链上；开放寻址法在发生冲突时按一定规则（如线性探测、二次探测）寻找下一个空位置。

装载因子等于已存元素个数除以数组长度。装载因子越高，冲突越多，性能越差。因此许多实现会在装载因子超过阈值时扩容，例如 Java 的 HashMap 默认阈值为 0.75。扩容需要重新计算所有元素的位置，单次代价是 O(n)，但均摊到每次插入仍然是 O(1)。

哈希表的最坏情况时间复杂度是 O(n)，例如哈希函数设计不当或遭到恶意构造的输入时，大量键落在同一个位置。一个好的哈希函数应当计算快速、分布均匀。另外，哈希表中的元素通常没有顺序；如果需要按键有序遍历或进行范围查询，应选择平衡二叉搜索树等有序结构，而不是哈希表。
