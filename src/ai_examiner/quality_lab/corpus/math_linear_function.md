title: 一次函数的图像与性质
---
形如 y = kx + b（k、b 为常数，且 k ≠ 0）的函数叫做一次函数。当 b = 0 时，y = kx 叫做正比例函数，正比例函数是特殊的一次函数。

一次函数的图像是一条直线。k 叫做斜率，决定直线的倾斜方向和程度：当 k > 0 时，y 随 x 的增大而增大，直线从左到右上升；当 k < 0 时，y 随 x 的增大而减小，直线从左到右下降。|k| 越大，直线越陡。b 是直线与 y 轴交点的纵坐标，称为截距。

画一次函数图像只需要确定两个点。通常取与坐标轴的交点：令 x = 0 得 y = b，令 y = 0 得 x = -b/k。例如 y = 2x - 4 与 y 轴交于 (0, -4)，与 x 轴交于 (2, 0)。

求一次函数解析式常用待定系数法：已知直线经过两点，把两点坐标代入 y = kx + b，解关于 k、b 的方程组。例如直线经过 (1, 3) 和 (3, 7)，可得 k = 2，b = 1。

一次函数常用于描述匀速变化的实际问题，如按固定单价计费。但如果实际问题中存在分段计费或起步价之后单价改变，就不能用单一的一次函数表示，而应使用分段函数。常见错误是忽略 k ≠ 0 的条件，把 y = b 这样的常数函数也当作一次函数。
