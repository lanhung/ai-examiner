# 校园客户端部署交接

本记录随校园客户端源码发布，不包含账号、会话编号、AppSecret、运行配置、备份清单、材料或成绩。

- 共享服务已从旧实例迁至 Casdao。切换时先停旧端写入，核对数据库快照与材料对象的摘要，再放行新端。不要同时在两台实例开放正式答卷写入。
- 网页预览身份使用独立空间，不得查看迁入的考试材料或成绩。部署时保留原有租户隔离和学校 API 限制；查看报告仍需当前账号的有效权限。
- 导入 `apps/wechat/` 后，在本机设置微信 AppID、`miniprogram/config.js` 中的 HTTPS API origin，并在微信后台配置对应合法域名。切换服务后重新登录、编译和预览；仓库故意不提供正式登录凭据。
- 独立网页见 [校园站部署和测试](../../apps/campus-web/README.md)。它与小程序共用业务 API，不替换原管理工作台；网站账号凭据库和共享业务数据应分别做受限备份。
- 小程序页面验收曾覆盖教师试答、个人答辩、角色切换、回执恢复和合成答卷的成绩隔离。开发工具通过不等于真机音频、弱网下载或并发容量已经验收。

本次 Git 归档不重新部署、迁移数据库、发布微信版本或重跑付费模型任务。
