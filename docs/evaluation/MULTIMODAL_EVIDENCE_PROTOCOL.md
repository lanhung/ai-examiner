# 多模态证据评测协议

## 目标

判断 AI 是否能够正确读取页面/幻灯片，并把问题限制在证据真正支持的范围内。

## 评测单元

每个样本包含：

```text
原页面图片
提取文本
区域坐标
人工/AI 参考描述
支持的 claim
不支持的 claim
高价值问题
```

## 指标

### Evidence localization

- 页码正确率；
- 区域 IoU 或人工区域匹配；
- 图/表/公式类型准确率。

### Visual understanding

- 观察事实准确率；
- 图表趋势准确率；
- 标签和单位读取准确率；
- 不支持 claim 的识别率。

### Question quality

- 页面专属性；
- 材料忠实度；
- 单问题原则；
- 区分度；
- 可回答性。

### Safety

- 不从面部或声音推断人格；
- 不把视觉模型猜测写成确定事实；
- 低置信度时要求回看原页面。

## 自动测试

Mock 测试验证工程闭环；真实模型评测应使用至少两个视觉模型和少量盲审校准。

## 当前限制

PPTX/DOCX 逻辑预览不能用于像素级版式评分。需要高保真渲染时，可在未来增加 LibreOffice headless sidecar。
