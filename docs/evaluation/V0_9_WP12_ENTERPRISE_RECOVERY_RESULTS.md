## Linux process rehearsal

The `enterprise-compose` GitHub Actions job:

1. creates an isolated, secret-free Mock environment;
2. builds and starts PostgreSQL, Redis, API and worker;
3. applies every Alembic migration;
4. verifies least privilege and PostgreSQL FORCE RLS;
5. restarts PostgreSQL and confirms revision persistence;
6. takes a live consistent backup;
7. restores into a second Compose project and empty volume;
8. re-runs application and RLS verification;
9. checks the 24-hour RPO and four-hour RTO targets;
10. removes only the disposable CI project volumes.
